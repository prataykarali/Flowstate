Chapter 2 Research: Overlapping-Key Interference
Empirical Benchmark
Overlapping Key Directions (2D)
1.0126 L2 Error
Writing non-orthogonal vector k₃ = [1/√2, 1/√2] corrupts earlier values stored at orthogonal keys k₁=[1,0] and k₂=[0,1].
Orthogonal Key Separation (3D)
0.0000 L2 Error (Exact Retrieval)
Zero error is achieved because keys are strictly orthogonal: ki · kj = 0.
Scientific Limit: Zero error is specific to idealized one-hot synthetic benchmarks, not a universal guarantee for dense learned representations.
Measured Results: chapter2_memory_benchmark.json (1 to 100 Association Steps)
Memory Capacity vs Physical Storage Scaling
Capacity Trade-Off
Fixed Recurrent State
36 Bytes (Constant)

Orthogonal & Slot Expansion
1,200 Bytes at 100 Keys
Eliminates interference by scaling linearly: supporting N independent associations requires dim(k) ≥ N.

Testing variable dimensions (d=3, 5, 8): dynamic allocation uses 64 Bytes versus 120 Bytes for fixed padded structures.
