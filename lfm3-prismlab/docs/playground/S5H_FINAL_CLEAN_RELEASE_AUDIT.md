## 12. Defects Found & Engineering Fixes Applied

During the clean-slate verification process, three specific operational defects were uncovered and immediately fixed:

### Defect 1: Port Re-binding Race Condition During CPU Model Swapping
- **Symptom**: Sequential requests switching between multimodal models on port 8188 (e.g. `vision` -> `audio`) occasionally returned HTTP 503 if the previous model process had not completely unbound the TCP socket before the new process attempted `bind()`.
- **Root Cause**: `LifecycleManager.stop()` waited for process termination but did not verify TCP socket release in the Linux networking stack before `start()` invoked `subprocess.Popen()`.
- **Correction**:
  1. Added `_wait_port_free(base_url, timeout=3.0)` in `prismlab/core/lifecycle.py` using non-blocking TCP socket connect probes to guarantee the port is completely free before returning.
  2. Enhanced `execute_selected()` in `prismlab/selected_chat.py` with process crash detection (`owned.poll() is not None`) and a transient grace period for teardown states rather than raising immediate fatal errors.

### Defect 2: Missing Activity Session ID in Test Turn Calls
- **Symptom**: Story Turn 1 and Trivia contestant answers initially returned HTTP 409 `ACTIVE_ACTIVITY_CONFLICT`.
- **Root Cause**: The gateway navigation locking system correctly requires any request executed within an active session to pass `activity_session_id`. The acceptance test script had omitted `activity_session_id` in its payload.
- **Correction**: Updated `s5h_clean_slate_production_acceptance.py` to supply `activity_session_id` on all active turn calls, matching the production client behavior in `playground/src/pages/AutoStoryShow.tsx` and `triviaLive.ts`.

### Defect 3: Hash Routing Discrepancy in Browser Audit
- **Symptom**: Browser audit navigated to `/#league` which defaulted to `/#world`.
- **Root Cause**: `routes.ts` defines the championship route as `championship` (`ROUTES[7].id = 'championship'`).
- **Correction**: Updated `s5h-browser-visitor-audit.mjs` to navigate to `/#championship`, capturing the verified live championship table and visual badges.
