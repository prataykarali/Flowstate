# PrismLab S0.6 visual design report

## Direction and composition

The Model World is now a twilight research observatory garden. The generated backdrop supplies a single curved floor, distant domes, water, botanical edges, and atmospheric depth. Six original interactive SVG mascots sit on the same terrace with contact shadows and character-colored light. A short introduction leads directly into the scene; a model spotlight and expandable architecture/benchmark details follow it. At narrow widths, the roster becomes two columns across three shared terrace bands.

The previous implementation used a long introduction, empty dark background, six small orbs, and separate animated oval pedestals. The updated screenshots show a larger shared scene and more prominent characters. A baseline screenshot was not present in this workspace, so the comparison is based on the inspected previous implementation.

## Characters and interaction

Original SVG geometry, accessories, `useId()` isolation, gaze tracking, blinking, and keyboard/touch selection remain in the React components. Each character has its own restrained idle gesture and selection light. Clicking or pressing Enter/Space gives a brief authored reaction, selects the model, updates the spotlight, and offers Playground and Research actions. Character lines were revised so they do not imply that a live model run occurred.

## Artwork, typography, and motion

- `public/assets/environment/observatory-garden.webp` is original OpenAI-generated artwork made for this task, compressed to 189,328 bytes. It contains no mascot or UI layer. See `public/assets/environment/ATTRIBUTION.md`.
- Self-hosted Outfit is used for headings and names; Manrope is used for body and navigation. Both came from the [Google Fonts repository](https://github.com/google/fonts) under SIL Open Font License 1.1. License texts are in `public/assets/fonts/`.
- Ambient motion uses CSS transforms on the existing SVGs. The old pedestal animation was removed. `prefers-reduced-motion: reduce` disables character idle animation.

## Verification

- `npm run typecheck`, `npm test` (4 passing tests), and `npm run build` passed.
- Browser audit passed: all eight routes render, selection updates the specification, SVG IDs have no duplicates, and no console or network errors were recorded.
- Checked 1440×900, 1024×768, and 390×844 layouts. No horizontal overflow was found. Reduced-motion emulation reported `animation: none` on mascot bodies.
- Screenshots: `world-1440.png`, `world-1024.png`, `world-390.png`, `playground-1440.png`, and `settings-1440.png`. `world-390-full.png` shows the full mobile composition.
- No dependency was added. New artwork is 189 KB; both fonts together are 276 KB. The original `characters/` prototype and Python backend were not edited.

## Scope and remaining weakness

Other pages received shared colors, typography, surface styling, clearer navigation, and small copy improvements. Their underlying layouts remain close to the S0 implementation. On mobile, the tall scene uses CSS terrace bands because a wide landscape illustration cannot show its physical floor behind all three rows at once.
